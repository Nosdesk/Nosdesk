## Default Permission

Allows the app to open the native share sheet for a file in its cache

#### This default permission set includes the following:

- `allow-share-file`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`share:allow-share-file`

</td>
<td>

</td>
</tr>

<tr>

</td>
